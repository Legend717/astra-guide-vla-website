\section{Related work}
\label{sec:related}

\paragraph{Foundation models for robot control.}
Language and vision-language models have been used to connect task reasoning with robot execution through affordance-based skill selection, robot API programs, and spatial objectives for motion planning \citepending{saycan,code-as-policies,voxposer}. Vision-language-action models (VLAs) combine pretrained visual-language representations with robot demonstrations to learn action prediction \citepending{rt2,openvla,pi05}. RoboICL and GPT-Policy explore in-context robot control with general-purpose VLMs, using demonstrations and interaction feedback to adapt behavior without updating model weights at deployment \citepending{roboicl,gpt-policy}. On RoboMME, direct Astra control generates Cartesian waypoints using sampled episode history \citepending{astra-direct}. Our harness instead relies on a trained VLA for routine motion, with Astra providing task reasoning, supervision, and direct intervention when needed.

\paragraph{Hierarchical execution and feedback.}
Inner Monologue incorporates environmental feedback into language-based planning \citepending{inner-monologue}. PonderPounce maintains episode context in a multimodal language model and asynchronously passes cognition tokens to a fast VLA, allowing high-level reasoning to inform low-level control \citepending{ponderpounce}. $\tau_0$-VLA uses execution memory and world-model-guided search to select subtasks for a low-level policy \citepending{tau0-vla}. More closely related to our setting is the three-tier Astra system, which separates planning, monitoring, and execution. Astra generates subgoals, a fine-tuned Qwen3-VL-4B monitor detects their completion, and a fine-tuned \pifive\ executes them \citepending{astra-three-tier}. Our harness extends Astra's role beyond subgoal planning to execution supervision and recovery. Astra assigns execution budgets, selects auxiliary monitors for earlier inspection, and directly intervenes when corrective control is needed.

\paragraph{Task memory and experience reuse.}
RoboMME evaluates manipulation tasks that require reasoning over past observations \citepending{robomme}. Existing approaches maintain task history in different forms, including SAM2Act+'s visual memory bank, MEM's short-horizon video and long-horizon text, SimpleMemVLA's sampled video context, and MemER's retrieval of relevant historical keyframes \citepending{sam2act,mem,simplememvla,memer}. These approaches provide historical context for decisions within an episode. Our harness likewise retrieves archived observations and maintains episode notes, but also accumulates experience that informs decisions across episodes.

Experience reuse beyond a single episode has been explored in Reflexion, which uses textual feedback to improve later attempts, and Voyager, which builds a library of reusable skills through interaction \citepending{reflexion,voyager}. ME-Brain-1.0 extends this direction to embodied intelligence by consolidating interaction trajectories into reusable experience and skills without retraining the underlying models \citepending{mebrain}. Our harness focuses on using such experience to supervise an existing VLA. Astra maintains revisable recommendations for subgoal selection, execution budgets, monitor selection, and recovery, together with their applicable conditions and supporting evidence. Astra can revise these recommendations based on episode outcomes and reuse them in later decisions.
